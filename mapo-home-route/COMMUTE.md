# 출퇴근 비교

`/commute`에서 로그인한 사용자의 관심 매물 최대 3개를 비교합니다. 관심 매물 화면의 **출퇴근 비교** 버튼으로도 들어갈 수 있습니다.

## 실행

1. `mapo-home-route` 폴더에서 `npm run install:ci`로 의존성을 설치합니다. `.env.example`을 `.env.local`로 복사한 뒤 `ODSAY_WEB_API_KEY=발급받은_URI_키`를 설정합니다. 기존 다른 키가 있다면 유지합니다. `.env.local`은 Git에서 제외됩니다.
2. ODsay 서비스 URI에 `localhost:5173`을 등록합니다.
3. `npm run dev -- --port 5173 --hostname 127.0.0.1`을 실행합니다.
4. 브라우저에서 `http://localhost:5173/commute`로 접속합니다. URI 인증 때문에 브라우저 주소는 `127.0.0.1` 대신 `localhost`를 사용합니다.

로컬 로그인은 기존 Sites 개발용 계정을 사용하며 운영 사이트 사용자 데이터와 분리됩니다. 출퇴근 비교와 요약 카드 레이아웃은 [운영 사이트](https://mapo-home-watch.sooyeon-jun-0389.chatgpt.site/commute)에 반영되어 있습니다. GitHub 푸시와 Sites 배포는 별도로 진행합니다. 모델 API는 사용하지 않습니다.

## 위치와 계산

- 원본 데이터에 정확한 좌표가 없으므로, 사용자가 원문 주소를 확인해 주소·장소 검색, 역·정류장 검색, 지도 선택 중 하나로 출발 위치를 지정합니다. 동 이름으로 좌표를 추정하지 않습니다.
- 주소 검색은 명시적인 검색 버튼으로만 Nominatim을 호출하며 서버 인스턴스에서 최소 1.1초 간격을 적용합니다. 상세 지번은 검색되지 않을 수 있습니다. `COMMUTE_GEOCODER_URL`로 Nominatim 형식의 다른 검색 공급자를 지정할 수 있습니다. 공개 서비스 확장 전 공급자의 용량·정책에 맞는 주소 검색 서비스를 정해야 합니다.
- 지도는 OpenStreetMap 타일을 사용합니다. 지도 초기 중심은 탐색을 위한 위치이며, 사용자가 선택하기 전에는 출발지나 목적지로 사용하지 않습니다.
- ODsay URI 키는 등록된 브라우저에서 직접 교통 API를 호출하는 공개 웹 키입니다. 서버 비밀 키로 취급하거나 모델 API 키와 혼용하지 않습니다. 설정 응답은 로그인 사용자에게만 반환하고 캐시하지 않습니다. 로컬 키는 빌드 설정에 주입하지 않습니다.
- 총 예상 시간은 ODsay 경로 시간 + 사용자가 역 기준 위치에 입력한 추가 도보입니다. 환승은 탑승 구간 수에서 1을 뺀 값입니다. 실제 출발 시각의 혼잡·지연·배차를 보장하지 않습니다.
- 빠른 순·환승 적은 순·도보 적은 순과 편도 시간·환승 제한은 이미 조회된 모든 대안 경로에 적용합니다. 각 방에서 조건을 충족하는 최상위 경로를 골라 방 사이 순위를 다시 계산합니다. 조건 변경만으로 API를 재호출하지 않습니다.
- 선택한 경로는 목적지 입력 아래의 작은 요약 카드에 시간·환승·도보, 출발·도착지, 노선을 표시합니다. 비교 조건과 상세 경로는 기본으로 접혀 있으며, 상세 경로를 펼치면 세로 타임라인과 대안 경로를 볼 수 있습니다. 다른 경로를 선택하면 상세 내용이 바뀌며, 정렬·필터를 변경하면 새 조건의 최상위 경로로 돌아갑니다. 대안 목록은 처음 2개를 표시하고 나머지는 더 보기로 펼칩니다.
- 목적지, 선택 좌표, 조회 결과는 화면 메모리에만 두며 앱 DB·브라우저 저장소에 저장하지 않습니다. 검색어/좌표는 위치·경로 조회를 위해 해당 외부 서비스에 전달됩니다. 새로고침하면 다시 선택해야 합니다.

## 검증

```sh
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test lib/commute.test.mjs
npm run build
```

단위 검증: 추가 도보 합산, 환승 0회 제한, 시간 제한, 정렬과 동점 처리, 잘못된 API 응답 배제.
실제 로컬 브라우저 검증: 로그인, 최대 3개 제한, 역·주소 검색, 지도 위치 선택, 3개 경로 조회, 조건 변경, 구간 상세.
