# 매물 업로드 표준 MAPO-1

2026-10-07부터 운영센터는 Listly 원본과 표준 엑셀을 같은 검증·변환 로직으로 처리한다. 원본 XLSX는 보존하고 변환한 사본을 사용한다. 기존 DB의 ID·가격 이력·관심 매물은 재작성하지 않는다.

## 파일 규칙

- 시트 `Sheet1`, 첫 행은 칼럼명, 다음 행부터 매물 1건씩. 최대 2,000건, 파일 5MB, API 요청 4MB.
- 원본: `SINGLE_YYYYMMDD_HHMMSS.xlsx` 또는 UTF-8 CSV.
- 표준: `MAPO_YYYYMMDD_HHMMSS.xlsx` 또는 UTF-8 CSV. 날짜·시각은 원본 수집시각을 유지한다.
- 칼럼은 `lib/standard-import.ts`의 `STANDARD_HEADERS` 26개를 모두 포함한다. 순서는 자유이며 중복 칼럼명은 거절한다.
- `형식버전`은 `MAPO-1`. 금액은 만원, 면적은 ㎡ 단위 숫자. 알 수 없는 값은 0으로 대체하지 않는다. 전세 월세는 0이다.
- 두 가격 조건은 `보증금2(만원)`·`월세2(만원)`에 실제 조합 그대로 저장한다. 최소 보증금과 최소 월세를 임의 조합하지 않는다.
- `수집시각`은 UTC ISO 문자열 또는 같은 시각의 Excel 날짜값이다. 파일명에 쓰는 시간은 한국 시간이다. 예: 파일명 `20261007_093929`, 수집시각 `2026-10-07T00:39:29.000Z`.

## 고정 칼럼

`형식버전`, `매물ID`, `매물명`, `자치구`, `동`, `유형`, `거래종류`, `보증금(만원)`, `월세(만원)`, `보증금2(만원)`, `월세2(만원)`, `전용면적(㎡)`, `층`, `방향`, `관리비`, `역거리`, `설명`, `확인등록일`, `원문URL`, `가격원문`, `검토상태`, `검토메모`, `원본파일`, `원본시트`, `원본행`, `수집시각`.

원문 링크가 있는 매물 ID는 `naver:원문번호`, 없는 매물은 기존 `snapshot:수집일:원본행`을 유지한다. 기존 테스트의 `test:1`~`test:5`도 유지하며 실제 매물 링크와 혼합하지 않는다. 임의의 네이버 링크·동·금액은 만들지 않는다.

## Listly 원본 변환

Listly 정리 도우미는 파일 선택 즉시 읽기·표준화·검증을 실행한다. 정상 파일은 기존 운영 목록과 비교하여 반영 대기를 만들고, 오류가 있으면 검토를 요청한다. 원문 가격과 보증금·월세·면적의 표준 값을 처음 5건 미리 보여주며, 전체 자료는 표준 엑셀로 내려받을 수 있다. 정해진 표준 규칙으로 처리하며 외부 생성형 AI에 자료를 전송하지 않는다. 운영 목록의 실제 반영은 운영자 확인 후에만 실행한다.

`LABEL-N` 열의 번호를 기준으로 매물명·가격·유형의 연속된 조합을 찾아 어제/오늘 수집 형태를 모두 읽는다. 24쌍의 고정 칼럼 수에 의존하지 않으며, 추가되거나 줄어든 LABEL/HREF 열도 인식한다. 이미지 개수나 VR 칼럼 추가에 의한 위치 이동을 허용하지만, 서로 다른 조합이 여러 개면 확인을 요구한다. 같은 이름의 LABEL/HREF 열은 거절한다. 전용면적·층·방향·관리비·거리·확인일·설명은 역할에 맞는 원문에서 읽는다. 설명에 있는 '전용25P' 같은 표현을 면적 필드로 잘못 읽지 않는다.

## 확인 필요 항목

형식 점검 결과는 전체 건수와 확인 필요 행·매물명·원문 링크를 보여준다. 표준 엑셀 다운로드에는 오류 행도 포함한다. `검토상태`가 `정상`이 아닌 행, 잘못된 금액·ID·시각 등이 있으면 기본적으로 반영을 막는다. 운영자는 확인 필요 행을 명시적으로 선택하여 제외하고 다시 검증할 수 있다. 정상 행의 임의 제외, 제외되지 않은 오류 행, 전체 행 제외는 서버에서 거절한다. 일부 행을 몰래 제외하거나 0으로 바꾸지 않는다. 서버도 독립적으로 검증하며 실패한 검증 요청은 운영 데이터·기존 검증 대기를 변경하지 않는다. 새 파일 선택 또는 제외 선택 변경 뒤에는 과거 검증 결과의 반영 버튼을 숨긴다.

제외 후에도 완료 건수는 원본 전체 건수와 대조한다. 예: 원본 1,050건, 제외 1건, 반영 1,049건이면 완료 건수에 1,050을 입력한다. 기존 전체 수집 확인 체크박스에서 제외 내역도 확인하고 반영한다. 서버는 `confirmExclusions`를 별도로 검사한다. 제외 행·매물명·사유·원문 URL은 검증 대기와 최근 30회 실행 대상 이력에 저장하고, 운영 작업 이력에 제외 건수를 남긴다. 기존 목록에 있던 제외 매물은 기존 이력을 보존하고 미수집으로 표시한다.

2026-10-07 원본 27행 `고려아카데미텔 1동`은 원문 자체의 `월세 1,000/57억 5,000` 오류를 사용자에게 확인했다. 표준 사본은 원문 텍스트·ID·링크를 보존하고 보증금/월세 숫자를 비워 `금액 확인 필요`로 표시한다. 사용자가 이 행만 제외하여 업로드하도록 요청했으며, 운영센터에서 27행을 선택하여 나머지 1,049건을 반영할 수 있다.
