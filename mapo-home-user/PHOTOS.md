# 매물 사진

- 운영자 표준 엑셀 `이미지URL`을 `imageUrl`로 저장·전달하고 사용자 카탈로그에서도 보존한다. 기존에 사진 필드가 없는 자료도 허용한다.
- 현재 수집원인 `https://landthumb-phinf.pstatic.net/` 링크만 허용한다. 엑셀과 저장된 URL은 그대로 보존한다. 화면에서는 검증된 `type=CW86_H86` 형태의 축소 옵션만 제거해 같은 경로의 원본 사진을 요청한다. 원본 로딩에 실패하면 작은 썸네일로 전환하고 확대하지 않는다. 사진은 브라우저에서 원문 URL로 읽으며 서버에 복사하지 않는다.
- 카드와 상세 화면의 사진은 가로 너비에 맞춰 채우며 넘치는 부분은 자른다. 사진을 누르면 별도 보기 창에서 `object-fit: scale-down`으로 전체 이미지가 보인다. 닫기 버튼이나 Escape로 이전 화면에 돌아간다. 상세 화면에서는 네이버 원문으로 이동할 수 있다. 링크가 없거나 로딩 실패하면 각각 안내한다.
- 이미 저장된 매물은 `data/listing-images.json`의 파일명·행·ID·매물명·원문 URL이 모두 일치할 때만 응답에 사진을 보완한다. 데이터베이스, 가격 이력, 관심 목록과 알림은 변경하지 않는다. 파일에는 2026-10-06 13:02:31 / 17:34:00 및 2026-10-07 09:39:29의 사용자가 제공한 Listly 원본에 있는 링크만 들어 있다. 다른 수집 파일로 추측하여 재사용하지 않는다.
- `scripts/verify-listing-photos.mjs`에서 보완 대상 일치 여부, URL 검증, 운영자 스키마·카탈로그 전달·가격 이력 보존을 검사한다.
